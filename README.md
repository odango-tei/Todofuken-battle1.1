このフォルダの15ファイルが公開用の全ファイルです。配布用ZIPも用意しています。GitHubで公開するときはZIPを展開し、中身をアップロードしてください。全225,111種類・町丁207,454種類、育成・図鑑・ガチャ6種類・CPU対戦・都市リーグ・天下統一・キャラデザを収録。オンライン対戦はありません。

## v1.0 島の施設と固有技

利尻町に「利尻訓練所」、壱岐市に「壱岐地形の庭」、神津島村に「神津島アイテム・地形交換所」を追加。建物の近くから専用画面に入れます。既存の北見・対馬の施設も維持しています。

訓練所は最初3枠。1分につき経験値2を獲得し、閉じている時間も反映します。覚醒と既存のレベル上限は維持し、編成したまま預けられます。ユーザーレベルは最大100。戦闘と収穫で経験値を得て、Lv11で4枠、Lv21で5枠になります。ユーザーレベルで戦闘能力は変わりません。

庭は1時間に1つ、最大24個まで地形が実ります。基礎N・Rの地形が実る際はSRが5％、SSRが1％。未所持なら獲得、上位レアならレベルを維持して昇格、それ以外は同レアのかけら1個になります。交換対象の政令指定都市175区は庭から除外しています。

野生の勝利で12％の確率で交換用コインを1枚獲得し、その内訳はA70％・B25％・C5％。都市リーグは勝利ごとにA1枚に加え、Bを20％・Cを5％で獲得します。交換所は日本時間0時と12時にラインナップと購入上限を更新。同じ時間帯は再読み込みでも同じです。区、通常コイン、N・Rランダムチケット、ガチャ1回券、なんでもN選択チケットを販売。更新ごとに0.5％でUのかたまり、0.1％でU選択チケットが入荷します。なんでもN選択は基礎SSRもNで獲得でき、上位レアを所持している場合は降格しません。ガチャ1回券は1回ガチャで優先使用します。既存の称号による全区獲得も維持しています。

渋谷区「スクランブル・クロス」は8方向から地形で交差攻撃。1発のダメージは通常投擲の0.7倍。新宿区「都庁フィーバー」は10秒間、攻撃・防御・速度33％アップ。大田区「飛行機アタック」は大田区の地形が飛行機に乗って貫通突撃します。北海道「北海道はでっかいどう」の投射地形をさらに大型化。奥州市と下呂市の弾も、球体の代わりに実際の地形を使用します。3つの新固有技はSR以上、CPUも同じ技を使用します。

追加データはブラウザ保存・旧方式のセーブコード・大規模セーブコードに対応。旧コードには初期値を補います。時刻は端末時計を利用するため、時計改変やデータ巻き戻しへの完全な対策ではありません。実機iPadと公開先での動作は未検証です。

## 編成

編成は専用の全画面です。上部の1〜3番を選んで仲間を配置し、前へ・後へで順番を変更します。名前・都道府県・SR以上・赤・緑・青・黄・無で検索できます。所持一覧の初期順は編成順です。色は見た目の分類だけで、能力や相性は変わりません。現在は全キャラに色があるため、無は該当なしです。順序は自動保存とセーブコードで維持され、CPU対戦にも反映します。

## 公開

このフォルダの中身をGitHubリポジトリのルートへアップロードし、Settings → Pages → Deploy from a branch → main → / (root) を設定します。別のブランチ名なら実際の名前を選んでください。公開URLで index.html が入口になります。

制作Workspace全体をリポジトリに置く場合は、付属の .github/workflows/pages.yml で github-pages/ だけを配信できます。この場合はSettings → Pages → SourceをGitHub Actionsにします。

GAS・対戦サーバー・CDNライブラリー・Git LFSは不要です。初回の約7.1MBと、必要になった町の形を配信元から取得します。file://による直開きには対応しません。

## 編成コンボ・選択チケット

同じ地方3体でHP・攻撃＋5％、同じ都道府県3体で＋10％。強い方だけを適用し、特殊コンボ11種は加算します。編成画面の「コンボ一覧」で条件と効果を確認できます。

交換所にN・R選択獲得チケットを1,000コイン・購入制限なしで販売します。全カテゴリの基礎N・Rから1体を選べ、覚醒済みの所持キャラも基礎がN・Rなら選べます。チケット枚数と交換所の週次購入履歴はブラウザ保存・セーブコードで維持します。湖ガチャのボタン色は水色・青へ統一しました。

## ガチャ説明・葛飾区の固有必殺

ガチャの不自然な文章と重複獲得の説明を修正しました。一律の短縮は行っていません。現在の抽選確率は下記の更新内容を参照してください。価格と通常ガチャのR以上確定は維持しています。

葛飾区の固有必殺「風情溢れる町」はSR以上で発動します。与えた実ダメージと同じ量のHPを回復し、使用時から5秒間、防御力が20％上がります。回復は最大HPまで。再使用は効果時間を更新し、防御倍率は重複しません。敵の葛飾区にも適用します。

## 新しい施設と大観覧車

江戸川区の固有必殺「大観覧車」は、プレイヤーの周囲で回転し、8秒間かけて大型化します。敵に触れると攻撃し、接触した敵弾を防ぎます。SR以上で発動します。

北海道・北見市の「北見クイズランド」は、都道府県と市区町村の地形4択クイズを各10問出題。正解ごとに都道府県5コイン、市区町村10コインです。建物の近くから別画面に入れます。

長崎県・対馬市の「海外の使者バトラー」では、208の国・地域の使者とCPU対戦できます。44種類の投げ方と国別の必殺技名を用意しました。北朝鮮は「超急落下」。大きな国は本体・投射物も地形の広がりに比例して大きく表示します。小国には視認性のため最低サイズを設けています。勝った国・地域を世界地図図鑑に記録します。国・地域ごとに200勝すると、その使者の投げ方を個別に解放します。同じ軌道の国でも勝利数は別々です。勝利数は勝利確定時に保存し、敗北や中断では増えません。これまでの勝敗回数は保存されていないため、従来の討伐済みデータは1勝として引き継ぎます。図鑑から世界地図を閲覧できます。国内ガチャのIDと収録数は変えていません。

途中のクイズと世界図鑑はブラウザ保存・セーブコードに対応します。世界地形はNatural Earthのパブリックドメイン資料を加工しています。

## 一人称フリーバトル

対戦メニューから一人称フリーバトルを選べます。自分の目線でエリア全体を移動し、移動・視点操作・投げる操作を分離しています。左スティックで移動、画面のスワイプで視点操作、投げるボタンで攻撃します。PCはWASDで移動、ドラッグで視点、スペースで投げます。海外の使者には世界地図の「一人称で挑む」から対戦できます。従来の対戦も残しています。設定の「戦闘操作」で「一人称・自由移動」を保存すると、次の野生・主・CPU・都市リーグ・海外の使者の戦闘にも適用されます。設定は同じブラウザに保存され、従来操作にも戻せます。天下統一チャレンジは従来操作です。

「一生ネットの宝物」は田所村・三浦市・遠野市の3体で、攻撃ごとに1％の確率で固定114514ダメージが発動。「パークパワー」は名前に公園を含む3体でHP・攻撃＋10％です。

## 追加の戦闘難易度

鬼の上に修羅・羅刹・魔神・極限を追加。敵HP・攻撃・行動速度が段階的に上がり、獲得コイン・経験値も増加します。従来の5段階は変更していません。野生・主・CPU戦に適用し、都市リーグ・海外の使者・天下統一チャレンジは従来どおり各モードの難易度です。南アフリカの3D地形と投射物は、レソト部分を内側の穴として保持しています。

## 湖の固有必殺・ガチャ確率・演出設定

湖553種の収録と育成は維持し、固有必殺は111種に整理しました。残り442種は通常の必殺を使用します。全47都道府県と、元の効果・軌道の組合せ102種を残すように選定しています。

通常ガチャ全国はSSR1％・SR10％・R24％・N65％。地方別の通常ガチャもN65％とし、SRとSSRは従来の割合を維持し、Rで調整します。オールスターはSSR1％・SR10％・R30％・N59％を維持。レアリティ内の各キャラを均等に抽選します。SSR対象がないガチャはSSR0％で、湖・過去・町丁・旧国藩の排出対象や基礎レアリティは変えません。通常11連のR以上確定でもSSR確率は上昇しません。価格は従来どおりです。

霞ヶ浦の輪郭を国土数値情報 W09-05 の湖岸から再処理し、255点から1,812点へ詳細化しました。オープンマップ上の湖も別途、実際の緯度経度から全国マップと同じ座標系へ変換し、1,644点の湖岸と島の穴を反映しました。湖の表示・ラベル・水域判定を同じ輪郭へ更新しています。3D図鑑での一律の間引きと、霞ヶ浦の湖岸を太らせる面取りをやめ、モデルと投げる地形にも同じ輪郭を使用しています。2005年基準の資料であり、現在の湖岸を保証するものではありません。北浦・外浪逆浦は別キャラクターのままです。

設定の「ドーパミンドバドバモード」をオンにした場合のみ、多重衝撃波・放射光・大量の光の飛沫・紙吹雪・勝利表示と重ねた効果音で、ヒット・勝利・ガチャを大幅に強調します。SSRや勝利では72粒の大きな演出を使います。激しい点滅、カメラ揺れ、時間停止は使いません。表示は最大6組に制限し、自動消去します。標準はオフ。確率・能力・報酬は変わりません。サウンドオフ・軽量描画・動きを減らす設定を優先します。

## 東京7区の固有必殺

荒川区「路面電車が通ります」は6秒間、移動操作で路面電車を操縦。北区「世界のAKABANE」は3つの赤い地形が相手を囲んで追尾突撃し、命中で少し押し出します。豊島区「池袋サンシャインビーム」は3秒間照射し、0.25秒ごとに通常投擲の0.25倍のダメージ。目黒区「目黒川の桜」は前方5本の桜で7秒防御します。

港区「高級住宅街の力」は、勝利コイン1.2倍とコイン6枚の雨のどちらかが発動。倍率は重複せず、通常戦・海外の使者・都市リーグの勝利報酬に適用します。都市リーグのA・B・Cコインやアイテムは増やしません。江東区「市場の活気」は15秒間、実際に与えた攻撃の命中ごとに、次のダメージ倍率を1.05倍ずつ累積。再使用は時間と倍率をリセットします。中野区「サブカルの聖地」は漫画・音楽・ゲームをイメージした4つの地形で連続攻撃します。

すべてSR以上で発動。CPUも同じ技を使用します。地形の輪郭・キャラクターの基礎能力・基礎レアリティ・従来のガチャ確率は変更していません。

## 新しい東京都の固有必殺

杉並区「アニメーション・フラッシュ」は、1発を通常投擲と同じ威力にして向きを変えながら35連射します。狛江市「五本松防衛」は、前方に5本の松を生やし、7秒間、触れた敵の投擲を防ぎます。松がある間も通常攻撃は使えます。稲城市「ジェットコースター突撃」は、毎回異なるコースにジェットコースターを出して突撃し、相手を貫きます。いずれもSR以上で発動し、通常の必殺ゲージを使います。CPUも同じ技を使います。キャラクターの基礎能力・基礎レアリティ・排出確率は変更していません。

## 編成・図鑑・育成

3画面は別画面のまま、深緑の見出し・生成りの背景・検索欄・カード・ボタンを共通デザインにしています。図鑑の地図・6カテゴリ・世界地図、編成の検索・並べ替え、育成・証の間・交換所はそのまま使えます。湖の水色と未所属の灰色、レアリティの縁色も維持しています。

## 投げ方編成

メニューの「投げ方」または編成画面の「投げ方編成」から開きます。基本・称号解放・使者から習得した投げ方を最大5つまで編成。並べ替え・検索・解除に対応し、自動保存します。対戦中は投げ方ボタンで一覧を開いて選択でき、キーボード1〜5でも切り替えられます。Qは編成順に切り替えます。習得した投げ方は通常攻撃に適用し、必殺は従来どおり各地形の固有技を使用します。投げるのは編成した地形です。一人称・天下統一にも対応します。カスタム調整は投げ方編成のボタンから引き続き使えます。

## 証のランク

U・Lv60・使用50回で通常の証を獲得。以降は累計使用100回で銅、200回で銀、500回で金、1000回でプラチナへ昇格。既存の証は保持し、既存の使用回数からランクを表示します。通常の証を初めて獲得する際の500コインは従来どおり、昇格による追加コインや能力倍率はありません。

## 青函トンネルと読み込み表示

青森県今別町と北海道知内町に青函トンネルの施設を配置。近くで入口ボタンを押すと、短い通過演出で反対側へ移動できます。移動に料金はかからず、所持地形や能力は変わりません。位置・経路・所要時間はゲーム用の簡略表現です。新しい地形キャラクターではないため、収録数やIDは変更しません。

起動時は受信バイト数と初期化工程に応じたゲージ・百分率・受信容量を表示します。時間経過だけで進む見せかけの割合ではありません。追加の町丁地形は必要時に読み込む従来方式を維持しています。UIで仲間や境界を指す「形」は「地形」に統一し、地名・「形状」「形式」などの用語・旧セーブ署名は変更していません。

## 保存

育成はブラウザ内の自動保存とローカル形式のセーブコードに対応します。全種所持のような大規模データは、収録順IDの連続範囲を圧縮して保存します。大規模コードは7万字の漢字体系を維持したv4形式で、この圧縮対応版が必要です。以前のコードは引き続き読み込めます。別のサイト・ブラウザからの自動移行ではないため、移行はセーブコードを使ってください。ブラウザデータ削除やプライベートモードに備えてコードを控えてください。キャラデザと3つの保存枠は同じブラウザ内に保存し、育成コードには含みません。見た目で能力・当たり判定は変わりません。
